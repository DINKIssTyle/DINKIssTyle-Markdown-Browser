# ⌨️ ショートカット
これはDKST Markdown Browserのショートカット一覧です。

## 一般的なショートカット
| アクション | Windows/Linux | macOS |
| :--- | :--- | :--- |
| 新規ドキュメント | Ctrl+N | ⌘+N |
| 新しいタブを開く | Ctrl+T | ⌘+T |
| 閉じたタブを再表示 | Ctrl+⇧+T | ⌘+⇧+T |
| 現在のタブを閉じる | Ctrl+W | ⌘+W |
| タブに移動 | Ctrl+1～9 | ⌘+1～9 |
| サイドバーの切り替え | Alt+S | ⌥+S |
| ファイルツリーサイドバーの切り替え | Alt+1 | ⌥+1 |
| アウトラインサイドバーの切り替え | Alt+2 | ⌥+2 |
| 検索サイドバーの切り替え | Alt+3 | ⌥+3 |
| 検索 | Ctrl+F | ⌘+F |

## リーダーモード
| アクション | Windows/Linux | macOS |
|---|---|---|
| ファイルを開く | Ctrl+O | ⌘+O |
| ホームに戻る | Ctrl+⇧+H | ⌘+⇧+H |
| 更新 | Ctrl+R | ⌘+R |
| テーマの変更 | Ctrl+K | ⌘+K |
| 履歴ナビゲーション | Ctrl+[ , Ctrl+] | ⌘+[ , ⌘+] |
| フォントサイズ | Ctrl++, Ctrl+- | ⌘++, ⌘+- |

## エディットモード
**💡 ヒント:** リーダーモードとエディターモードの切り替えは、ショートカットキー **`Ctrl + E`** (Windows/Linux) または **`⌘ + E`** (macOS) を使うと非常に高速です！
| 機能 | ショートカット/使い方 | 説明 |
|---|---|---|
| コードショートカットを検索 | `/` + 矢印キー Enter または機能名を入力してEnter | キーボード上の利用可能なすべてのコードショートカットを検索します。 |
| AIに質問する | テキストを選択してから `/` キーを押す | 選択したテキストに関してAIからヘルプを受け取ります。 |
| 行コメントの切り替え | Ctrl+/ ⌘+/ | 現在の行へのコメントを切り替えます。|
| インデント | Ctrl+],Ctrl+[ , ⌘+], ⌘+[ | 現在の行のインデントを調整します。|
| 一般テキスト | OSのデフォルトショートカットに従う | 一般的なテキスト編集機能はOSのデフォルトショートカットに従います。 |
