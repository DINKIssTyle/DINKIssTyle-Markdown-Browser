## 🚀 バージョン 2.1 の主な変更点

### サイドバーの導入

タブバーの左側にサイドバーを開くボタンが表示されました。`ショートカット: CTRL+ALT+S (macOS: CMD+OPT+S)`
* **サイドバーの構成**:
  * **ファイルツリー**: 開いているファイルのホームフォルダをファイルディレクトリ構造として表示します。選択することでMarkdownファイルや画像ファイルを直接閲覧できます。
  * **アウトライン**: Markdownドキュメントのアウトラインを表示します。
  * **検索**: バージョン2.0までメインツールバーにあった検索機能がここに統合されました。

### 小さな変更点だが重要なもの

* **ポップアップツールチップ**: ハイパーリンクにマウスカーソルを合わせると、遷移先の住所が表示されます。

## 2.1 ベータ2
### 追加・バグ修正・調整

* **追加：Markdownレンダリングの構文ハイライト**

### Python
```python
# フィボナッチ数列
def fibonacci(n: int) -> list[int]:
    result = []
    a, b = 0, 1

    while len(result) < n:
        result.append(a)
        a, b = b, a + b

    return result


if __name__ == "__main__":
    print("Fibonacci:", fibonacci(10))
```

### Bash

```bash
#!/usr/bin/env bash

set -euo pipefail

NAME="${1:-World}"

if [[ "$NAME" == "admin" ]]; then
  echo "Welcome, administrator."
else
  echo "Hello, $NAME!"
fi

for file in *.txt; do
  [[ -e "$file" ]] || continue
  echo "Found text file: $file"
done
```

## 2.1 ベータ3
### 追加機能

- ファイルツリーから編集中のドキュメントにリンクや画像を直接挿入できます。
- **表の挿入の視覚化**: `/table` で表を挿入してみてください。キーボード矢印キーを使って直感的に挿入できます。
- **絵文字挿入の高度化**: カテゴリ別に分類されたモーダルウィンドウにより、キーボード操作のみでアイテムを閲覧・選択し挿入できます。

### バグ修正と調整

- **ポップアップツールチップを修正**し、多言語対応を追加しました。
- **絵文字トーストの削除**: トーストメッセージ内の絵文字をGoogle Material Symbolsに変更しました。
- **ファイルツリーフィルター**: フィルターアイコンをクリックすると、対応ファイルのみが表示されます。

## 2.1 ベータ4

### バグ修正と調整

- **サイドバーショートカットの追加**: ファイルツリーはALT+1、アウトラインはALT+2、検索はALT+3です。
- **サイドバーキーボードナビゲーション**: Tabキーで子要素へ移動し、矢印キーでサイドバー全体を移動できます。
- **サイドバーの改善 - アウトラインの書式設定**: 見出しに基づいて太字やフォントサイズが区別され、フォーマットボタンでオン/オフを切り替えられます。
- **TASKの書式レンダリング**: 不要な「•」がついていましたが、これは削除され意図通りにレンダリングされます。

## 2.1 ベータ5

### 追加事項

- **多言語文書翻訳の生成**: エディターで「Translate Document」ボタンを押し、希望の言語を選択すると、現在編集中の文書全体を一度に翻訳できます。
- **番号付きリストのオプション**: 設定 > エディター > 一般 には、番号付きリストを継続するオプションがあり、デフォルトは 1. 1. 1 です。これはマークダウンの標準です。このオプションを 1. 2. 3. に変更すると、以前のように増加する番号を使用できます。
- **3種類のツールバー**: オプションから、マークダウン編集の習熟度に応じて、初心者、ルーキー、プロのツールバーを選択できます。
- **閉じたタブの再表示**: CTRL+SHIFT+T で閉じられたタブを再度開くことができます。

### バグ修正および改善点

- **ショートカットキーの変更**: 機能が拡張されたため、ショートカットキーが変更されました。開始ページ下部のショートカットキー文書をご確認ください。
- **編集状態インジケーター**: 文書が編集されているもののまだ保存されていない場合、文書タブに警告アイコンが表示されます。
- **別名での保存**: 文書を別の名前で保存できます。
- **ファイルツリーの右クリックメニュー**: 名前変更、コピー、削除機能が追加されました。これらの機能は文書が編集中の場合にのみ動作します。
- **ファイルツリーの右クリックメニュー**: 新しいタブで開くメニューが追加されました。閲覧モードでのみ動作します。
- **タブを閉じるアニメーション**: タブを閉じるときに、タブバーにアニメーションが追加されました。
