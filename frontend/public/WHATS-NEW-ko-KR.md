# 3.0 새로운 기능
### 모바일 환경에 최적화된 DKST Markdown Browser를 만나보세요. iPhone, Android Phone, iPad, Android Tablet에서 사용 가능합니다.

### 개선 사항 (Improvements)
* **iOS, Android UI**: 모바일(스마트폰)과 타블렛(iPad/Android Tablet) 환경에서 모든 UI 요소의 폰트 사이즈가 Apple Human Interface Guidelines (iOS/iPadOS Typography) 표준 규격에 일치하도록 최적화합니다

### 버그 수정 (Bug Fixes)
* **details, summary 태그 랜더링**: 내용 요약/접기 랜더링 버그를 수정했습니다.





## 이전 체인지로그

<details>
<summary><b>버젼 2.2 기간 변경 사항</b></summary>
  
### 주요 변경 사항 (Highlights)
* **프런트 매터(Front Matter) 완벽 지원**
  * **인식 및 표시:** 프런트 매터가 포함된 문서를 열면 주소창에 느낌표 버튼이 나타나며, 문서 탭에는 메타데이터에 정의된 제목이 표시됩니다.
  * **템플릿 삽입:** 편집 모드에서 느낌표 버튼을 눌러 제목(문서 첫 줄), 작성자(설정 값 연동), 날짜(작성 시점), 태그, 초안 여부 등이 포함된 기본 템플릿을 쉽게 삽입할 수 있습니다.
* **편집 및 미리보기 모드 고도화**
  * **화면 분할 제어:** 가로/세로 분할 방향 전환 및 편집기와 미리보기의 배치 위치를 자유롭게 바꿀 수 있습니다.
  * **비율 조절:** 분할 막대를 드래그하여 비율을 조절할 수 있으며, 더블 클릭 시 1:1 비율로 초기화됩니다.
  * **미리보기 켜기/끄기:** 툴바 버튼이나 단축키(`Ctrl+G` / `CMD+G`)를 통해 미리보기를 쉽게 제어할 수 있습니다.
* **앱 내 업데이트 지원** (데스크탑 버젼)
  * 웹사이트를 방문하지 않고 앱 내(설정 → 업데이트)에서 바로 새 버전을 확인하고 다운로드할 수 있습니다. (현재는 자동 업데이트 대신 수동 다운로드 지원)
#### 개선 사항 (Improvements)
* **환경설정 UI 전면 개편:** 설정 화면이 더 현대적이고 세련된 디자인으로 새롭게 단장되었습니다.
* **인터페이스 사용자화:**
  * **메인 툴바:** 새 문서, 편집 모드, 번역, 서체 크기, 테마 버튼의 표시 여부를 설정에서 켜고 끌 수 있습니다.
  * **스크롤바:** 사용자 지정 액센트 컬러가 적용되어 현재 스크롤 위치를 직관적으로 확인할 수 있으며, 표시 시점(항상 또는 스크롤할 때)을 선택할 수 있습니다.
* **히스토리 탐색 피드백:** Windows, macOS, Linux 전반에서 트랙패드 제스처를 통한 히스토리(전/후) 이동 시 시각적 피드백과 애니메이션의 부드러움이 대폭 향상되었습니다.
* **최근 목록 정리 개선:** '최근 목록 제거' 클릭 시, 사용자가 고정한 파일은 제외하고 목록을 비우도록 개선되었습니다.
* **CJK(한중일) 언어 호환성 향상**
  * **줄바꿈 및 커밋 개선:** `CJK IME Enter Fix` 옵션 활성화 시(macOS, Linux), CJK 문자 입력 중 엔터키 한 번만으로 부드럽게 줄바꿈이 가능해졌습니다.
* **입력 충돌 해결:** 목록 작성이나 명령어(`/`) 사용 시, 엔터 또는 방향키 입력으로 인해 문자가 잘못 커밋되거나 다음 동작으로 넘어가지 않던 현상을 수정했습니다.
#### 버그 수정 (Bug Fixes)
* **텍스트 선택 오류 수정:** 탭 이동이나 설정 창을 연 후 다시 화면을 스크롤할 때, 마지막 편집 위치부터 새 위치까지 텍스트가 의도치 않게 선택되던 문제를 해결했습니다.
* **저해상도 환경 지원:** 1280x720 등 해상도가 낮은 환경에서 타이틀바가 사라지는 문제를 막기 위해, 실행 시 자동으로 최대화 모드로 열리도록 수정했습니다.
* **macOS 탐색 오류 수정:** macOS에서 트랙패드 및 마우스를 이용한 히스토리 전후 이동이 작동하지 않던 문제를 해결했습니다.

<details>
<summary><b>버젼 2.1 기간 변경 사항</b></summary>
  
### 주요 변경 사항 (Highlights)
- **통합 사이드바 도입**: 파일 트리, 개요(Outline), 검색 기능이 통합된 사이드바 추가 (CTRL+ALT+S / macOS: CMD+OPT+S)
- **마크다운 구문 강조(Syntax Highlight)**: Python, Bash 등 코드 블록 렌더링 시 구문 강조 추가
#### 추가된 사항 (New Features)
- **사이드바 전용 단축키**: 파일 트리(ALT+1), 개요(ALT+2), 검색(ALT+3) 단축키 추가
- **에디터 삽입 기능 강화**: 파일 트리에서 하이퍼링크 및 이미지를 편집 중인 문서로 직접 삽입하는 기능 추가
- **표 삽입 시각화**: /table 명령어 입력 후 키보드 방향키를 이용해 직관적으로 표를 삽입하는 기능 추가
- **고급 이모지 삽입**: 키보드 탐색이 가능하고 카테고리별로 분류된 이모지 삽입 모달 창 추가
- **AI 다국어 번역 및 맞춤법 검사**: 편집 중인 문서를 원하는 언어로 일괄 번역하거나 맞춤법을 검사·교정하는 기능 추가
- **뷰어 전용 번역**: 편집 없이 현재 문서를 임시로 번역하여 보거나 번역본을 저장할 수 있는 기능 추가
- **목록 및 서식 옵션**: 순서 있는 목록(Ordered List)의 번호 증가 방식(1. 1. 1. 또는 1. 2. 3.) 선택 기능과 사용자 지정 형광펜 색상 선택 기능 추가
- **수준별 툴바 제공**: 사용자의 마크다운 숙련도에 따라 3가지 에디터 툴바(Beginner, Rookie, Pro) 세트 선택 기능 추가
- **뷰어 표시 설정**: 마크다운 뷰어의 기본 글꼴 변경 기능 및 여백 3단계 조절 기능 추가
- **탭 및 파일 관리**: 닫은 탭 다시 열기(CTRL+SHIFT+T), 다른 이름으로 저장, 최근 연 파일 목록 북마크(핀 고정) 기능 추가
#### 개선 사항 (Improvements)
- **팝업 툴팁 및 UI 개선**: 하이퍼링크 호버 시 목적지 주소 표시 및 다국어 지원, 이모지 토스트 알림을 Google Material Symbols로 변경
- **사이드바 사용성 강화**: 키보드 탭(Tab) 및 방향키 탐색 지원, 개요(Outline) 서식을 제목 크기에 따라 굵기/크기가 구분되도록 개선
- **파일 트리 편의성 향상**: 필터 클릭 시 지원되는 파일만 표시, 열려있는 파일 삭제 시 해당 탭 자동 종료, 우클릭 메뉴에 읽기 모드 전용 '새 탭에서 열기' 추가
- **편집 및 탭 경험 개선**: 미저장 상태를 나타내는 경고 아이콘 표시, 다른 파일 열기 시 새 탭에서 열림, 탭 닫기 애니메이션 추가, 편집 탭 복귀 시 이전 스크롤 및 커서 위치 기억
- **AI 및 작업 처리 고도화**: 번역 시 마지막 선택 언어 기억, OpenAI 및 LM Studio 모드에서 LLM 실시간 스트리밍(Delta) 응답 표시
- **다중 작업 안정성 확보**: 다중 탭 편집 시 탭 간 작업 내역 완벽 격리, 탭을 전환해도 번역/맞춤법 검사 작업이 유지되며 범용 진행률 표시줄로 상태 지속 표시
- **작업 스케줄링**: LLM 작업 진행 중 새 요청이 들어오면 이전 작업 완료 후 순차적으로 처리되도록 개선
- **시작 페이지 설정**: 최근에 열린 항목의 표시 개수를 사용자가 직접 조절할 수 있도록 개선
- **기능 통합 및 시각적 안정화**: 유사 기능 그룹화 및 통합, 읽기/편집 모드 전환 시 발생하는 화면 깜빡임 문제 제거
- **디자인 일관성**: DKST 시리즈 문서와의 일관성을 유지하기 위해 문서 아이콘 디자인 세부 조정
#### 버그 수정 (Bug Fixes)
- **성능 최적화**: 설치된 글꼴이 많은 환경에서 앱을 실행할 때마다 폰트를 다시 불러와 준비 시간이 길어지던 시작 속도 저하 문제 수정
- **AI 프롬프트 오류**: 에디터에서 AI 프롬프트 창을 닫아도 화면에 계속 남아있던 가시성 문제 수정
- **AI 맞춤법 검사 오류**: LLM 응답 파싱 로직을 개선하여 맞춤법 검사(SpellCheck)가 간헐적으로 실패하던 문제 수정
- **렌더링 오류**: TASK 포맷 렌더링 시 불필요한 '•' 기호가 함께 출력되던 문제 수정
- **다이어그램 가독성**: 클래스 다이어그램 렌더링 시 배경과 텍스트 색상의 대비가 부족해 글자가 잘 보이지 않던 문제 수정
- **단축키 충돌 해결**: 확장된 기능들로 인해 발생한 단축키 충돌 문제를 해결하고 관련 단축키 일괄 조정 (시작 페이지 하단 문서 반영)
</details>
