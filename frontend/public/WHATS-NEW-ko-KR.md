### 추가 및 버그 수정 및 개선 사항

* **추가: 마크다운 렌더링 구문 강조 표시**

### Python
```python
# 피보나치 수열
def fibonacci(n: int) -> list[int]:
    result = []
    a, b = 0, 1

    while len(result) < n:
        result.append(a)
        a, b = b, a + b

    return result


if __name__ == "__main__":
    print("Fibonacci:", fibonacci(10))
```

### Bash

```bash
#!/usr/bin/env bash

set -euo pipefail

NAME="${1:-World}"

if [[ "$NAME" == "admin" ]]; then
  echo "Welcome, administrator."
else
  echo "Hello, $NAME!"
fi

for file in *.txt; do
  [[ -e "$file" ]] || continue
  echo "Found text file: $file"
done
```

## 2.1 베타4

### 버그 수정 및 개선 사항

- **사이드바 단축키 추가**: 파일 트리는 ALT+1, 개요는 ALT+2, 검색은 ALT+3.
- **사이드바 키보드 탐색**: Tab 키는 자식 요소로 이동하고, 화살표 키는 사이드바 전체를 탐색합니다.
- **사이드바 개선 - 개요 서식**: 제목에 따라 굵은 글꼴 및 글꼴 크기가 구분되며, 서식 버튼을 사용하여 토글할 수 있습니다.
- **TASK 형식 렌더링**: 불필요한 •가 붙어 있었습니다. 이제 제거되었으며 의도대로 렌더링됩니다.

## 2.1 베타5

### 추가 사항

- **다국어 문서 번역 생성**: 편집기에서 `Translate Document` 버튼을 누르고 원하는 언어를 선택하면 현재 편집 중인 문서의 번역본을 한 번에 생성할 수 있습니다.
- **순서 있는 목록 옵션**: 설정 > 편집기 > 일반에 순서 있는 목록 계속 옵션이 있으며 기본값은 1. 1. 1입니다. 마크다운 표준입니다. 이 옵션을 1. 2. 3.으로 변경하면 이전처럼 증가하는 숫자를 사용할 수 있습니다.
- **세 가지 편집기 도구 모음**: 옵션에서 마크다운 편집 숙련도에 따라 초급, 루키 또는 프로 도구 모음 중에서 선택할 수 있습니다.
- **닫은 탭 다시열기**: `CTRL+SHIFT+T`로 닫은 탭을 다시 열수 있습니다.

### 버그 수정 및 개선 사항

- **단축키 변경**: 기능이 확장됨에 따라 단축키가 변경되었습니다. 시작 페이지 하단의 단축키 문서를 확인해 주세요.
- **편집 상태 표시기**: 문서가 편집되었지만 아직 저장되지 않은 경우 문서 탭에 경고 아이콘을 표시합니다.
- **다른 이름으로 저장**: 문서를 다른 이름으로 저장할 수 있습니다.
- **파일 트리 우클릭 메뉴**: 이름 바꾸기, 복사 및 삭제 기능이 추가되었습니다. 이 기능들은 문서가 편집 중일 때만 작동합니다.
- **파일 트리 우클릭 메뉴**: 새 탭으로 열기 메뉴가 추가되었습니다. 읽기 모드에서만 작동합니다.
- **탭 닫힘 애니메이션**: 탭을 닫을 때 탭 바에 애니메이션이 추가되었습니다.

### 버그 수정 및 개선 사항

- **탭간 격리 강화**: 여러 탭 동시 편집시 탭간 작업 히스토리를 분리하고, 섞이지 않도록 합니다.

- **Translate Document, Spellcheck 작업 유지**: 작업 중 다른 탭으로 이동 상태에서 작업이 완료되고, 해당 탭으로 돌아가면 작업 된 내용을 유지하고 있어야 합니다.
- **Translate Document, Spellcheck 작업 표시**: 작업 중 다른 탭으로 이동해도 작업 중인 프로그레스바가 상시 볼수 있어야 합니다.
- **LLM 순차 처리**: LLM 작업이 진행 중일 때 새로운 요청이 들어오면, 이전 작업이 완료된 후 순차적으로 처리되어야 합니다.
- **최근 파일 목록**: 북마크 버튼을 클릭해서 최근 목록에 고정할 수 있습니다.
- **함수 공통화, 통합**: 비슷한 기능의 함수들을 공통화로 묶고 통합했습니다.
- **편집 중인 탭 복원**: 다시 돌아온 편집 중인 탭에서 스크롤 위치와 커서 위치를 기억해야 합니다.
- **UI 안정화**: 읽기 모드와 편집 모드 간 전환 시 발생하는 화면 흔들림 현상을 제거했습니다.
