## 🚀 Version 2.1 主要变更

### 引入侧边栏

在标签栏的左侧出现了一个打开侧边栏的按钮。`快捷键：CTRL+ALT+S (macOS: CMD+OPT+S)`
* **侧边栏组成**:
  * **文件树 (File Tree)**：以文件目录结构显示打开文件的主文件夹。您可以通过选择直接查看 Markdown 和图像文件。
  * **大纲 (Outline)**：查看您的 Markdown 文档的大纲。
  * **搜索 (Search)**：搜索功能（在 2.0 版本之前位于主工具栏）已合并至此处。

### 小但重要的改动

* **弹出式工具提示 (Popup Tooltip)**：当鼠标悬停在超链接上时，会显示目标地址。

## 2.1 Beta2
### 新增、错误修复和润色

* **新增：Markdown 渲染的语法高亮**

### Python
```python
# Fibonacci sequence
def fibonacci(n: int) -> list[int]:
    result = []
    a, b = 0, 1

    while len(result) < n:
        result.append(a)
        a, b = b, a + b

    return result


if __name__ == "__main__":
    print("Fibonacci:", fibonacci(10))
```

### Bash

```bash
#!/usr/bin/env bash

set -euo pipefail

NAME="${1:-World}"

if [[ "$NAME" == "admin" ]]; then
  echo "Welcome, administrator."
else
  echo "Hello, $NAME!"
fi

for file in *.txt; do
  [[ -e "$file" ]] || continue
  echo "Found text file: $file"
done
```

## 2.1 Beta3
### 新增

- 从文件树直接在编辑文档中插入链接和图像。
- **表格插入可视化**：尝试使用 `/table` 插入表格。您可以使用键盘箭头键直观地插入它。
- **表情符号插入高级功能**：一个按类别划分的模态窗口允许您仅使用键盘即可浏览和选择项目进行插入。

### 错误修复和润色

- **修复弹出式工具提示**；增加了多语言支持。
- **移除表情符号提示**：现在可以将提示消息中的表情符号更改为 Google Material Symbols。
- **文件树过滤器**：点击过滤器图标将只显示受支持的文件。

## 2.1 Beta4

### 错误修复和润色

- **添加侧边栏快捷键**：文件树是 ALT+1，大纲是 ALT+2，搜索是 ALT+3。
- **侧边栏键盘导航**：Tab 键移动到子元素；箭头键在整个侧边栏中移动。
- **改进侧边栏 - 大纲格式化**：加粗文本和字体大小是根据标题区分的，可以使用格式按钮切换开关。
- **TASK 格式渲染**：移除了不必要的 •。它现在已被移除并按预期渲染。

## 2.1 Beta 5

### 新增功能

- **多语言文档翻译生成**: 在编辑器中点击“翻译文档”按钮并选择所需语言，即可一次性生成当前编辑文档的译本。
- **有序列表选项**: 在设置 > 编辑器 > 通用中有一个“有序列表继续”选项，默认值为 1. 1. 1。这是 Markdown 标准。如果您将此选项更改为 1. 2. 3.，就可以像以前一样使用递增的数字。
- **三种编辑器工具栏**: 您可以在选项中根据您的 Markdown 编辑熟练程度选择初级、新手或专业工具栏。
- **重新打开已关闭的标签页**: 您可以使用 CTRL+SHIFT+T 重新打开已关闭的标签页。

### Bug 修复和改进

- **快捷键更改**: 由于功能扩展，快捷键已发生更改。请参阅起始页底部的快捷键文档。
- **编辑状态指示器**: 如果文档已被编辑但尚未保存，则在文档标签上显示警告图标。
- **另存为**: 您可以将文档另存为不同的名称。
- **文件树右键菜单**: 添加了重命名、复制和删除功能。这些功能仅在文档正在编辑时有效。
- **文件树右键菜单**: 添加了在新标签页中打开的菜单。仅在读取模式下有效。
- **标签关闭动画**: 在关闭标签页时，标签栏增加了动画效果。






## 2.1 Beta 6

### AI 功能增强
- **拼写检查器**：检查和纠正文档中的拼写错误。


### 错误修复与改进

## 2.1 Beta 7

### Bug Fixes and Improvements

- **修复 `SpellCheck` 问题**: 改进了 LLM 响应解析，解决了拼写检查失败的问题。
- **实时 LLM 响应显示**: 在以下情况下显示来自 LLM 的流式增量消息：
  - **OpenAI 兼容模式**: `Ask AI Prompt Box`（询问 AI 提示框）、`Translate Document`（翻译文档）
  - **LM Studio 模式**: `Ask AI Prompt Box`（询问 AI 提示框）、`Translate Document`（翻译文档）、`SpellCheck`（拼写检查）



## 2.1 Beta 8

### 新增功能

- **高亮颜色**: 您可以选择想要的任何高亮颜色。

### Bug 修复和改进

- **增强标签页隔离**: 当多个标签页同时编辑时，它会隔离工作历史记录，防止混淆。
- **进度条小部件**: 已被制作成通用小部件，所有功能都可以普遍使用它。
- **维护翻译文档、拼写检查操作**: 在进行操作期间切换到另一个标签页时，工作内容应被维护并在返回该标签页时可见。
- **显示翻译文档、拼写检查操作**: 即使切换标签页，进行中的操作的进度条也必须保持可见。
- **LLM 顺序处理**: 如果在 LLM 操作进行中收到新请求，它必须在先前任务完成后按顺序处理。
- **最近文件列表**: 您可以通过点击书签按钮将文件固定到最近列表中。
- **功能统一和集成**: 相似的功能已被分组到通用功能中并进行了集成。
- **恢复编辑标签页**: 当返回已编辑的标签页时，应用程序必须记住滚动位置和光标位置。
- **UI 稳定化**: 移除了在阅读模式和编辑模式之间切换时出现的屏幕闪烁问题。



## 2.1 Beta 9

## 2.1 Beta 10

### 新增功能

- **查看器翻译功能**: 您可以在不编辑的情况下翻译当前文档。选项：临时翻译、保存已翻译的文档



## 2.1 Beta 11

### 改进与更改

- **类图渲染修复**：解决了文本颜色与背景对比度不足的问题。
- **应用启动速度提升**：修复了在安装了许多字体的环境中，字体需要在每次启动时重新加载导致的准备时间过长的问题。
- **文档图标更改**：对文档图标进行了微调，使其与DKST系列文档保持一致。
- **AI提示框**：修复了AI提示框在从编辑器中关闭后仍然可见的问题。
