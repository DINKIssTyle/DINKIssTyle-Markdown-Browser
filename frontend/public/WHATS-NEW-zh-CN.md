# 更新内容

## 2.2.2

#### 新功能

- **支持元数据 (Front Matter)**：当打开包含元数据的 Markdown 文档时，地址栏会出现感叹号按钮，并且标签页会显示元数据中定义的标题。
- **插入元数据**：在编辑模式下，按下感叹号按钮会插入一个包含标题、作者、日期、标签、草稿状态等的基本模板。插入元数据后，标题默认为 Markdown 文档的第一行，作者使用“设置 → 编辑器选项卡 → 作者姓名”中的值，日期在创建时填写。
- **自定义主工具栏按钮显示**：您可以在“设置 → 外观”中配置在主工具栏上显示的按钮（新建文档、编辑模式、翻译、字体大小、主题）。每个功能都有唯一的快捷键。
- **改进历史记录导航**：解决了在 macOS 上使用触控板或鼠标时，历史记录导航（前进/后退）无响应的问题。增加了跨 Windows、macOS 和 Linux 的触控板手势的可视化反馈。

#### 改进

- **修复编辑器光标移动期间的文本选择问题**：解决了在执行标签页导航或打开设置窗口等操作后滚动时，文本从上次编辑位置到新位置被选中的问题，尤其是在光标移动到不可见区域时。
- **增强低分辨率支持**：解决了在低分辨率工作区（如 1280x720）上标题栏无法显示的问题，现在设备分辨率低时会自动以最大化模式运行。

## 2.2.1

#### 新增功能 (New Features)
- **编辑模式横向/纵向切换**: 在编辑模式中，您可以设置预览和分割方向。
- **调整编辑模式编辑器/预览位置**: 您可以更改编辑模式下编辑器和预览的布局位置。
- **调整编辑模式分割比例**: 通过拖动分割条来调整编辑器和预览的分割比例。提示：双击分割条可重置为 1:1 比例。
- **在编辑模式中关闭预览**: 您可以在编辑器工具栏中轻松开关预览。提示：快捷键 Ctrl+G / CMD+G

#### 改进 (Improvements)
- **设置界面全面翻新**: 以现代而时尚的设计焕然一新。
- **最近列表清除按钮**: 现在清空列表的操作不包括固定的文件。

## Version 2.1 期间变更

### 主要变更 (Highlights)
- **引入集成侧边栏**: 添加了集成了文件树、大纲 (Outline) 和搜索功能的侧边栏 (CTRL+ALT+S / macOS: CMD+OPT+S)
- **Markdown 语法高亮 (Syntax Highlight)**: 渲染 Python、Bash 等代码块时添加了语法高亮

#### 新增功能 (New Features)
- **侧边栏专用快捷键**: 添加了文件树 (ALT+1)、大纲 (ALT+2)、搜索 (ALT+3) 快捷键
- **增强编辑器插入功能**: 添加了从文件树直接将超链接和图像插入到正在编辑的文档中的功能
- **表格插入可视化**: 输入 `/table` 命令后，可使用键盘方向键直观地插入表格
- **高级 Emoji 插入**: 添加了支持键盘导航并按分类归类的 Emoji 插入模态窗口
- **AI 多语言翻译和拼写检查**: 添加了将正在编辑的文档批量翻译为所需语言或检查并纠正拼写的功能
- **仅查看器翻译**: 添加了无需编辑即可临时翻译并查看当前文档或保存翻译版本的功能
- **列表和格式选项**: 添加了有序列表 (Ordered List) 编号递增方式 (1. 1. 1. 或 1. 2. 3.) 的选择功能以及自定义荧光笔颜色选择功能
- **按难度提供工具栏**: 添加了根据用户的 Markdown 熟练程度选择 3 种编辑器工具栏 (Beginner, Rookie, Pro) 集合的功能
- **查看器显示设置**: 添加了更改 Markdown 查看器默认字体功能以及 3 级边距调节功能
- **标签页和文件管理**: 添加了重新打开已关闭标签页 (CTRL+SHIFT+T)、另存为、以及在最近打开文件列表中添加书签（固定）的功能

#### 改进事项 (Improvements)
- **弹出提示框及 UI 改进**: 鼠标悬停在超链接上时显示目标地址并支持多语言，将 Emoji 吐司通知更改为 Google Material Symbols
- **增强侧边栏易用性**: 支持键盘 Tab 键和方向键导航，改进大纲 (Outline) 格式，使其根据标题级别区分加粗和字号
- **提升文件树便利性**: 点击过滤器时仅显示支持的文件，删除已打开的文件时自动关闭对应标签页，在右键菜单中添加只读模式专用的“在新标签页中打开”
- **改进编辑与标签页体验**: 显示表示未保存状态的警告图标，打开其他文件时在新标签页中打开，添加标签页关闭动画，返回编辑标签页时记住之前的滚动和光标位置
- **AI 及任务处理升级**: 翻译时记住上次选择的语言，在 OpenAI 和 LM Studio 模式下实时显示 LLM 流式 (Delta) 响应
- **保障多任务稳定性**: 多标签页编辑时完全隔离标签页间的操作历史，切换标签页时仍保持翻译/拼写检查操作，并通过通用进度条持续显示状态
- **任务调度**: 当 LLM 操作正在进行中收到新请求时，将在前一任务完成后按顺序依次处理
- **起始页设置**: 改进为允许用户手动自定义显示的最近打开项目数量
- **功能整合与视觉稳定**: 分组并整合类似功能，消除在阅读/编辑模式切换时发生的屏幕闪烁问题
- **设计一致性**: 微调文档图标设计，以保持与 DKST 系列文档的一致性

#### 错误修复 (Bug Fixes)
- **性能优化**: 修复了在安装了较多字体的环境下每次启动应用时都要重新加载字体导致准备时间变长、启动速度下降的问题
- **AI 提示词框错误**: 修复了在编辑器中关闭 AI 提示词窗口后仍留在屏幕上的显示问题
- **AI 拼写检查错误**: 改进 LLM 响应解析逻辑，修复了拼写检查 (SpellCheck) 偶尔失败的问题
- **渲染错误**: 修复了渲染 TASK 格式时会额外输出不必要 '•' 符号的问题
- **图表可读性**: 修复了渲染类图 (Class Diagram) 时背景与文本颜色对比度不足导致文字难以看清的问题
- **解决快捷键冲突**: 解决了因功能扩展引起的快捷键冲突问题，并对相关快捷键进行了统一调整（已反映在起始页底部的文档中）
