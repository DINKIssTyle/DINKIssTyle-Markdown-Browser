# ⌨️ 快捷键
这是 DKST Markdown Browser 的快捷键列表。

## 通用快捷键
| 操作 | Windows/Linux | macOS |
| :--- | :--- | :--- |
| 新建文档 | Ctrl+N | ⌘+N |
| 打开新标签页 | Ctrl+T | ⌘+T |
| 恢复关闭的标签页 | Ctrl+⇧+T | ⌘+⇧+T |
| 关闭当前标签页 | Ctrl+W | ⌘+W |
| 跳转到标签页 | Ctrl+1~9 | ⌘+1~9 |
| 切換侧边栏 | Alt+S | ⌥+S |
| 切換文件树侧边栏 | Alt+1 | ⌥+1 |
| 切換大纲侧边栏 | Alt+2 | ⌥+2 |
| 切換搜索侧边栏 | Alt+3 | ⌥+3 |
| 搜索 | Ctrl+F | ⌘+F |

## 阅读模式
| 操作 | Windows/Linux | macOS |
| :--- | :--- | :--- |
| 打开文件 | Ctrl+O | ⌘+O |
| 返回主页 | Ctrl+⇧+H | ⌘+⇧+H |
| 刷新 | Ctrl+R | ⌘+R |
| 更改主题 | Ctrl+K | ⌘+K |
| 历史记录导航 | Ctrl+[ , Ctrl+] | ⌘+[ , ⌘+] |
| 字体大小 | Ctrl++, Ctrl+- | ⌘++, ⌘+- |

## 编辑模式
**💡 小贴士：** 使用快捷键 **`Ctrl + E`** (Windows/Linux) 或 **`⌘ + E`** (macOS) 可以非常快速地在阅读模式和编辑模式之间切换！
| 功能 | 快捷键/用法 | 说明 |
|---|---|---|
| 搜索代码快捷键 | `/` + 方向键回车 或 输入功能名称回车 | 在键盘上搜索所有可用的代码快捷键。 |
| 询问 AI | 选择文本后按 `/` 键 | 就所选文本向 AI 求助。 |
| 切換行注释 | Ctrl+/ ⌘+/ | 在当前行切换注释。|
| 缩进 | Ctrl+],Ctrl+[, ⌘+], ⌘+[ | 调整当前行的缩进。|
| 通用文本 | 遵循操作系统默认快捷键 | 一般文本编辑功能遵循操作系统的默认快捷键。 |
