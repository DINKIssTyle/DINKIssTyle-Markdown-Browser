* **추가: 마크다운 렌더링 구문 강조 표시**

### Python
```python
# 피보나치 수열
def fibonacci(n: int) -> list[int]:
    result = []
    a, b = 0, 1

    while len(result) < n:
        result.append(a)
        a, b = b, a + b

    return result


if __name__ == "__main__":
    print("Fibonacci:", fibonacci(10))
```

### Bash

```bash
#!/usr/bin/env bash

set -euo pipefail

NAME="${1:-World}"

if [[ "$NAME" == "admin" ]]; then
  echo "Welcome, administrator."
else
  echo "Hello, $NAME!"
fi

for file in *.txt; do
  [[ -e "$file" ]] || continue
  echo "Found text file: $file"
done
```

## 2.1 베타4

### 버그 수정 및 개선 사항

- **사이드바 단축키 추가**: 파일 트리는 ALT+1, 개요는 ALT+2, 검색은 ALT+3.

- **TASK 형식 렌더링**: 불필요한 •가 붙어 있었습니다. 이제 제거되었으며 의도대로 렌더링됩니다.

## 2.1 베타5

### 추가 사항

- **다국어 문서 번역 생성**: 편집기에서 `Translate Document` 버튼을 누르고 원하는 언어를 선택하면 현재 편집 중인 문서의 번역본을 한 번에 생성할 수 있습니다.
- **순서 있는 목록 옵션**: 설정 > 편집기 > 일반에 순서 있는 목록 계속 옵션이 있으며 기본값은 1. 1. 1입니다. 마크다운 표준입니다. 이 옵션을 1. 2. 3.으로 변경하면 이전처럼 증가하는 숫자를 사용할 수 있습니다.
- **세 가지 편집기 도구 모음**: 옵션에서 마크다운 편집 숙련도에 따라 초급, 루키 또는 프로 도구 모음 중에서 선택할 수 있습니다.

### 버그 수정 및 개선 사항

- **단축키 변경**: 기능이 확장됨에 따라 단축키가 변경되었습니다. 시작 페이지 하단의 단축키 문서를 확인해 주세요.
- **편집 상태 표시기**: 문서가 편집되었지만 아직 저장되지 않은 경우 문서 탭에 경고 아이콘을 표시합니다.
- **다른 이름으로 저장**: 문서를 다른 이름으로 저장할 수 있습니다.
- **파일 트리 우클릭 메뉴**: 이름 바꾸기, 복사 및 삭제 기능이 추가되었습니다. 이 기능들은 문서가 편집 중일 때만 작동합니다.
