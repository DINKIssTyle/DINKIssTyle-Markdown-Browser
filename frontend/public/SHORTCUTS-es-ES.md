# ⌨️ Atajos
Esta es la lista de atajos para el Navegador Markdown DKST.

## Atajos Comunes
| Acción | Windows/Linux | macOS |
| :--- | :--- | :--- |
| Nuevo Documento | Ctrl+N | ⌘+N |
| Abrir Nueva Pestaña | Ctrl+T | ⌘+T |
| Reabrir Pestaña Cerrada | Ctrl+⇧+T | ⌘+⇧+T |
| Cerrar Pestaña Actual | Ctrl+W | ⌘+W |
| Ir a Pestaña | Ctrl+1~9 | ⌘+1~9 |
| Alternar Barra Lateral | Alt+S | ⌥+S |
| Alternar Barra Lateral del Árbol de Archivos | Alt+1 | ⌥+1 |
| Alternar Barra Lateral de Esquema | Alt+2 | ⌥+2 |
| Alternar Barra Lateral de Búsqueda | Alt+3 | ⌥+3 |
| Buscar | Ctrl+F | ⌘+F |

## Modo Lector
| Acción | Windows/Linux | macOS |
|---|---|---|
| Abrir Archivo | Ctrl+O | ⌘+O |
| Ir al Inicio | Ctrl+⇧+H | ⌘+⇧+H |
| Refrescar | Ctrl+R | ⌘+R |
| Cambiar Tema | Ctrl+K | ⌘+K |
| Navegación Historial | Ctrl+[ , Ctrl+] | ⌘+[ , ⌘+] |
| Tamaño de Fuente | Ctrl++, Ctrl+- | ⌘++, ⌘+- |

## Modo Edición
**💡 Consejo:** ¡Cambiar entre el Modo Lector y el Modo Editor es muy rápido usando el atajo **`Ctrl + E`** (Windows/Linux) o **`⌘ + E`** (macOS)!
| Característica | Atajo/Uso | Descripción |
|---|---|---|
| Buscar Atajos de Código | `/` + Tecla Flecha Intro o escribir nombre de la función Intro | Busca todos los atajos de código disponibles en el teclado. |
| Preguntar a la IA | Seleccionar texto y luego presionar la tecla `/` | Recibe ayuda de la IA sobre el texto seleccionado. |
| Alternar Comentario de Línea | Ctrl+/ ⌘+/ | Alterna el comentario en la línea actual. |
| Sangría | Ctrl+],Ctrl+[, ⌘+], ⌘+[ | Ajusta la sangría de la línea actual. |
| Texto General | Seguir los atajos predeterminados del SO | Las funciones de edición de texto general siguen los atajos predeterminados del sistema operativo. |
