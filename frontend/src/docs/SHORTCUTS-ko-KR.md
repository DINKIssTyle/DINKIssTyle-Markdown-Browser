# ⌨️ 단축키
이것은 DKST 마크다운 브라우저의 단축키 목록입니다.

## 일반 단축키
| 작업 | Windows/Linux | macOS |
| :--- | :--- | :--- |
| 새 문서 | Ctrl+N | ⌘+N |
| 새 탭 열기 | Ctrl+T | ⌘+T |
| 닫은 탭 다시 열기 | Ctrl+⇧+T | ⌘+⇧+T |
| 현재 탭 닫기 | Ctrl+W | ⌘+W |
| 탭 이동 | Ctrl+1~9 | ⌘+1~9 |
| 사이드바 토글 | Alt+S | ⌥+S |
| 파일 트리 사이드바 토글 | Alt+1 | ⌥+1 |
| 개요 사이드바 토글 | Alt+2 | ⌥+2 |
| 검색 사이드바 토글 | Alt+3 | ⌥+3 |
| 검색 | Ctrl+F | ⌘+F |

## 읽기 모드
| 작업 | Windows/Linux | macOS |
|---|---|---|
| 파일 열기 | Ctrl+O | ⌘+O |
| 홈으로 이동 | Ctrl+⇧+H | ⌘+⇧+H |
| 새로고침 | Ctrl+R | ⌘+R |
| 테마 변경 | Ctrl+K | ⌘+K |
| 히스토리 탐색 | Ctrl+[ , Ctrl+] | ⌘+[ , ⌘+] |
| 글꼴 크기 | Ctrl++, Ctrl+- | ⌘++, ⌘+- |

## 편집 모드
**💡 팁:** 리더 모드와 편집 모드 간의 전환은 단축키 **`Ctrl + E`** (Windows/Linux) 또는 **`⌘ + E`** (macOS)를 사용하여 매우 빠르게 할 수 있습니다!
| 기능 | 단축키/사용법 | 설명 |
|---|---|---|
| 코드 단축키 검색 | `/` + 화살표 키 Enter 또는 기능 이름 입력 후 Enter | 키보드에 있는 모든 사용 가능한 코드 단축키를 검색합니다. |
| AI에게 질문하기 | 텍스트 선택 후 `/` 키 누르기 | 선택한 텍스트에 관해 AI로부터 도움을 받습니다. |
| 프리뷰 토글 | Ctrl+G (Windows/Linux), ⌘+G (macOS) | 편집 중 프리뷰 창을 표시하거나 숨깁니다. |
| 줄 주석 토글 | Ctrl+/ ⌘+/ | 현재 줄에 주석을 토글합니다. |
| 들여쓰기 | Ctrl+],Ctrl+[, ⌘+], ⌘+[ | 현재 줄의 들여쓰기를 조정합니다. |
| 일반 텍스트 | OS 기본 단축키 따르기 | 일반 텍스트 편집 기능은 OS 기본 단축키를 따릅니다. |
