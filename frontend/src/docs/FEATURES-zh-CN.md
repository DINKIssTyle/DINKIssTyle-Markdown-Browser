# 功能特性

本文档描述了 DKST Markdown Browser 的功能。
DKST Markdown Browser 允许您阅读、编辑或创建新的 Markdown 文档。

## 通用功能

- **打开 Markdown**: 打开 Markdown 文件。
- **侧边栏 - 文件树**: 浏览已打开文档的目录结构。
- **侧边栏 - 搜索**: 在已打开的文档和子文件夹中搜索关键词。
- **图像查看器**: 通过文件树提供浏览和缩放已打开图像的基本功能。
- **键盘可访问性**: 大多数功能都可以使用键盘访问或导航。
- **支持的扩展名**: `.md`, `.markdown`

## 阅读器
#### DKST Markdown Browser 在浏览超链接的 Markdown 文档方面表现出色，并提供以下功能：

- **侧边栏 - 大纲**: 可视化地显示 Markdown 文档的结构，并像目录一样组织它，允许快速跳转到特定位置。
- **超链接导航**: 就像在网页浏览器中一样浏览超链接的 Markdown 文档。
- **主页功能**: 第一个打开的文档作为主页，即使在通过超链接导航到其他文档时也可以轻松返回它。
- **字体大小调整**: 使用按钮或键盘快捷键轻松调整文档字体大小。
- **浅色/深色主题**: 根据您的偏好选择浅色或深色主题。
- **打印功能**: 打印文档。
- **渲染引擎**: 在 `Marked` 和 `Remark` 之间进行选择。
  - 已渲染的项目：
    - **公式**: 使用 `katex*` 将 LaTeX 公式渲染为 HTML。
    - **图表**: 使用 `Mermaid` 将 Mermaid 代码块渲染为 SVG。
    - **语法高亮**: 使用 `highlight.js` 渲染代码块。

## 编辑器

#### DKST Markdown Browser 通过嵌入 `CodeMirror` 提供了一个现代化的 Markdown 文档编辑环境。

- **语法高亮**: 支持语法高亮，提高编辑时的可读性，允许您在设置中选择预设或配置自定义调色板。
- **`/` 快捷键**: 编辑时按下 `/` 可以使用工具栏而无需鼠标点击。
- **插入链接**: 轻松插入 `URLs` 或 `本地文档`。插入 `本地文档` 使用相对路径，使文档创建变得方便。
- **插入图像**: 轻松插入 `URLs` 或 `本地图像`。插入 `本地图像` 使用相对路径，使文档创建变得方便。
- **通过侧边栏 - 文件树插入**: 从文件树中选择文档、文件或图像，然后使用右键菜单将该项直接插入到编辑器光标位置。
- **智能路径判断以进行插入**: 当插入文档或图像时，如果路径包含空格，它将被用 `<` 和 `>` 包裹以保证通用性。
- **编辑期间链接的文档**: 如果您点击正在编辑的文档中的超链接，该文档将在查看器中显示。提供一个浮动按钮可返回正在编辑的文档或在新标签页中打开它。
- **编辑器和查看器滚动同步**: 同步编辑屏幕和渲染查看器之间的滚动位置。这可以在选项中禁用。
- **查找和替换**: 在正在编辑的文档内搜索或批量替换文本。
- **CJK 兼容模式**: 可用一种与 `CodeMirror` 和东亚输入法“Marked Text”输入法兼容的模式，可防止出现不必要的空行。
- **编辑器字体大小调整**: 使用按钮或键盘快捷键轻松调整编辑窗口的字体大小。

>[!TIP] 有关 [默认快捷键](SHORTCUTS.md)。使用快捷键非常方便。

## 带 AI 辅助的编辑器
DKST Markdown Browser 利用本地 LLM 提供 AI 辅助；请在编辑器设置中的 AI 部分进行配置和切换此功能。

- **AI 功能工具栏**: 激活后，编辑器左下角会出现一个 `AI` 浮动按钮。
  - 点击 AI 按钮可暂停此功能。
  - 点击展开按钮可显示或隐藏整个 AI 功能工具栏。
     - **温度 (Temperature)**：调整温度以控制 AI 回复的创造性。较高的温度会导致更具创意的 AI 回复。
     - **自动完成 (Autocomplete)**：切换填充中间（FIM）。选择合适的 LLM 模型对于正常运行是必要的。
     - **上下文+ (Context+)**：使用部分前面的和后面的文本作为上下文来协助用户。这可能需要更多的上下文预算和处理时间。
     - **Github 兼容 (Github Compatible)**：如果您正在为 GitHub 书写文档，AI 会尝试符合 GitHub Flavored Markdown (GFM) 规范的协助。
     - **跟我谈谈 (Talk to me)**：AI 会处理用户的回复，并**每次都**简要报告处理的内容。

### 尝试 AI 功能

#### 通过文本选择获取 AI 辅助
1. 选择您正在编辑的句子。选中一个句子后，AI 提示窗口就会出现。
1. 按 `/` 可将提示直接输入到提示窗口中。
1. 可以从简单地开始尝试：`改进句子`、`翻译成英语`
1. 所选的句子将被改进或翻译。

提示示例：“整理成表格”、“用 div 包裹并设置宽度为 128px 的居中对齐”、“改为小写”、“用更简单的术语重写句子”、“拼写检查”、“绘制图表”

#### 不选择文本获取 AI 辅助
1. 按 `/` 并选择 `Ask AI` (Enter) 以弹出 AI 提示窗口。
1. 您也可以使用快捷键调用 AI 提示：`CTRL+/` 或 `⌘+/`
1. 可以从简单地开始尝试：`用表格列出 10 种水果和蔬菜`、`以 Markdown 格式简述苹果的好处`
1. 您将看到水果和蔬菜被组织成表格，或者得到一个类似 LLM 的回复，说明苹果的好处。

提示示例：“在一个代码块中画一只猫”、“编写一个 Python Hello World 示例”

>[!Note] 在 DKST Markdown Browser 中运行的 LLM 不会保存对话的上下文。这是为了忠实于其作为工具的角色，它不会记住先前的对话。此外，它也无法参考任何外部信息，如互联网、当前时间或位置。

- **推荐的 LLM 模型**
   - 使用 `3B~4B` 范围内的 LLM 模型，并且该模型具有有限或可切换的“推理”能力。
   - **AI 辅助的质量**很大程度上取决于您使用的 LLM 模型。
