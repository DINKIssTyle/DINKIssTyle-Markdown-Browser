# 機能

本ドキュメントでは、DKST Markdown Browserの機能について説明します。
DKST Markdown Browserを使用すると、Markdownドキュメントを読み取り、編集したり、新しいドキュメントを作成したりできます。

## 共通機能

- **Markdownを開く**: Markdownファイルをオープンします。
- **サイドバー - ファイルツリー**: 開いているドキュメントのディレクトリ構造を閲覧します。
- **サイドバー - 検索**: 開いているドキュメントやサブフォルダ内のキーワードを検索します。
- **画像ビューア**: ファイルツリーを通じて、開いている画像の閲覧や拡大・縮小といった基本的な機能を提供します。
- **キーボード操作**: ほとんどの機能をキーボードでアクセスまたは操作できます。
- **対応拡張子**: `.md`, `.markdown`

## リーダー
#### DKST Markdown Browserは、ハイパーリンク化されたMarkdownドキュメントの閲覧に優れており、以下の機能を提供します。

- **サイドバー - アウトライン**: Markdownドキュメントの構造を視覚的に表示し、目次のように整理することで、特定の場所へ素早くジャンプできます。
- **ハイパーリンクナビゲーション**: ウェブブラウザのようにハイパーリンク化されたMarkdownドキュメントを閲覧できます。
- **ホーム機能**: 最初に取り込まれたドキュメントがホームとして機能し、ハイパーリンクを介して他のドキュメントを閲覧中でも容易に戻ることができます。
- **フォントサイズ調整**: ボタンやキーボードショートカットを使用して、ドキュメントのフォントサイズを簡単に調整できます。
- **ライト/ダークテーマ**: 好みに応じて、ライトテーマとダークテーマを選択できます。
- **印刷機能**: ドキュメントを印刷します。
- **レンダリングエンジン**: `Marked`と`Remark`から選択できます。
  - レンダリングされる項目:
    - **数式**: `katex*`を使用してLaTeXの数式をHTMLにレンダリングします。
    - **図表**: `Mermaid`を使用してMermaidコードブロックをSVGにレンダリングします。
    - **構文ハイライト**: `highlight.js`を使用してコードブロックをレンダリングします。

## エディター

#### DKST Markdown Browserは、`CodeMirror`を埋め込むことで、モダンなMarkdownドキュメント編集環境を提供します。

- **構文ハイライト**: エディット中の可読性を向上させるために構文ハイライトをサポートしており、設定でプリセットを選択したりカスタムカラーパレットを設定したりできます。
- **`/` ショートカット**: 編集中に`/`を押すことで、マウスをクリックすることなくツールバーの機能を使用できます。
- **リンク挿入**: `URL`や`ローカルドキュメント`を簡単に挿入できます。`ローカルドキュメント`を挿入する場合、相対パスを使用するため、ドキュメント作成が便利です。
- **画像挿入**: `URL`や`ローカル画像`を簡単に挿入できます。`ローカル画像`を挿入する場合、相対パスを使用するため、ドキュメント作成が便利です。
- **サイドバー - ファイルツリー経由での挿入**: ファイルツリーからドキュメント、ファイル、または画像を選択し、右クリックメニューを使用して、エディターのカーソル位置にそのアイテムを直接挿入できます。
- **挿入のためのインテリジェントなパス判断**: ドキュメントや画像を挿入する際、パスにスペースが含まれている場合、普遍性を保つために`<`と`>`で囲まれます。
- **編集中にリンクされたドキュメント**: 編集中のドキュメント内でハイパーリンクをクリックすると、そのドキュメントがビューアに表示されます。編集中のドキュメントに戻るか、新しいタブで開くためのフローティングボタンが提供されます。
- **エディターとビューアのスクロール同期**: 編集画面とレンダリングされたビューア間のスクロール位置を同期します。これはオプションで無効にできます。
- **検索と置換**: 編集中のドキュメント内でテキストを検索または一括置換できます。
- **CJK互換モード**: `CodeMirror`および東アジア入力方式の「Marked Text」入力方法と互換性のあるモードで利用でき、不要な空行を防ぎます。
- **エディターのフォントサイズ調整**: ボタンやキーボードショートカットを使用して、編集ウィンドウのフォントサイズを簡単に調整できます。

>[!TIP] [デフォルトショートカット](SHORTCUTS.md)について学ぶ。ショートカットを使うと非常に便利です。

## AIアシスト付きエディター
DKST Markdown Browserは、ローカルLLMを利用したAIアシスト機能を提供しています。この機能を設定したり切り替えたりするには、エディター設定のAIセクションを確認してください。

- **AI機能ツールバー**: 有効にすると、エディターの左下隅に`AI`フローティングボタンが表示されます。
  - AIボタンをクリックすると、機能を一時停止できます。
  - 展開ボタンをクリックすると、AI機能ツールバー全体を表示または非表示にできます。
     - **Temperature（温度）**: AIの応答の創造性を制御するために温度を調整します。高い温度は、より創造的なAIの応答につながります。
     - **Autocomplete（自動補完）**: Fill-in-the-Middle (FIM) を切り替えます。適切なLLMモデルを選択することが、正常な動作に必要です。
     - **Context+**: 前後のテキストの一部をコンテキストとして使用し、ユーザーを支援します。これにはより多くのコンテキストバジェットと処理時間が必要になる場合があります。
     - **Github Compatible（GitHub互換）**: GitHub向けにドキュメントを作成している場合、AIはGitHub Flavored Markdown (GFM) の仕様に準拠した支援を試みます。
     - **Talk to me（私と話す）**: AIがユーザーの応答を処理し、その処理内容を簡潔に**毎回**報告します。

### AI機能の試用

#### テキスト選択によるAIアシストの利用
1. 編集している文を選択します。文を選択すると、AIプロンプトウィンドウが表示されます。
1. `/`を押すと、プロンプトをプロンプトウィンドウに直接入力できます。
1. 以下のように軽く試してみてください：「文を改善」「英語に翻訳」
1. 選択した文が改善または翻訳されます。

プロンプトの例：「表に整理」「divで囲み、幅128pxで中央揃えにする」「小文字に変更」「より簡単な言葉で書き直す」「スペルチェック」「図として描く」

#### テキスト選択なしでのAIアシストの利用
1. `/`を押し、「Ask AI」（Enter）を選択すると、AIプロンプトウィンドウが表示されます。
1. ショートカット `CTRL+/` または `⌘+/` を使ってAIプロンプトを呼び出すこともできます。
1. 以下のように軽く試してみてください：「果物と野菜を10個表にまとめる」「リンゴの利点をMarkdown形式で簡潔に書く」
1. 果物と野菜が表として整理されたもの、またはリンゴの利点がLLMのような応答で表示されます。

プロンプトの例：「コードブロックの中に猫を描く」「PythonのHello Worldの例を書く」

>[!Note] DKST Markdown Browser で動作する LLM は、会話のコンテキストを保存しません。これは、ツールとしての役割に忠実であり、以前の会話を記憶しないためです。さらに、インターネットや現在時刻、場所などの外部情報に参照することはできません。

- **推奨される LLM モデル**
   - `Reasoning` が限定的または切り替え可能な `3B～4B` の範囲の LLM モデルを使用してください。
   - **AI アシスタンスの品質**は、使用する LLM モデルによって大きく異なります。
