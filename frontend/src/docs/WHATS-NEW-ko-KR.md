# 3.0 모든 플랫폼으로의 확장
<div align="center"><img src="icon-512.png" width="128"/></div>

<div align="center" style="font-size: 1.2rem; font-weight: 700;"> 가볍고 우아한 크로스플랫폼<br>마크다운 뷰어 및 에디터!<br><br>이제 Windows, macOS, Linux, iOS, iPadOS 및 Android에서 사용 가능합니다.<br><br></div>

## 3.0.7

### 🎛️ 공통
* **번역 및 맞춤법 지원 언어 추가**: 설정에서 원하는 언어를 추가하여 사용 가능합니다.
* **코드 블록 복사 버튼**: 우측 상단에 고정되지 않던 문제 해결
* **메인 툴바 테마 버튼**: 처음 사용자에게 테마 버튼은 설정에서 켤수 있는 옵션입니다.

### 🖥️ macOS
* **편집 모드 버그 수정**: 수정 사항을 적용하고 종료할 때 앱이 멈추는 현상이 있었습니다.

### 🍎 macOS, iPadOS, iOS

* **Apple intelligence 도입**: 지원 환경에서 AI 제공자를 Apple Intelligence로 선택할 수 있으며, 이 경우 별도의 LLM 서버가 필요 없습니다. 다만, 문맥 길이의 제약으로 인해 기능이 원활하지 않을 수 있습니다.

### 📱 Android, iPadOS/iOS
* **Ask AI 호출 개선**: 태블릿 및 모바일에서 탭으로 선택된 텍스트에 대한 Ask AI 프롬프트 창이 호출되지 않던 문제를 수정했습니다.



## 3.0.6

### 🎛️ 공통

* **에디터 하단 확보**: AI 툴바에 가려지지 않도록 에디터 하단을 확보합니다.
* **AI 툴바가 화면에 남아있는 문제**: 편집 탭이 아닌 상태에서 AI 툴바가 사라지지 않는 문제를 해결합니다.


## 3.0.5

### 🖥️ Windows
- 편집 모드 도구 모음에서 취소 버튼이 작동하지 않는 문제 수정
### 🖥️ Linux
- 마크다운으로 생성되지 않은 새 문서 파일 수정

## 3.0.4

### 🎛️ 공통

* **비침해적 OS 파일 연결**: Non-intrusive File Association 기능을 통해 .txt, .py, .c, .m 등 다양한 일반 텍스트 및 소스 코드 파일을 열 수 있습니다. 이는 최소한의 개입을 통한 파일 연결 방식입니다.
* **코드 및 스크립트 편집 지원**: 다양한 코드나 스크립트 소스를 구문 강조 기능을 사용하여 편집하고 열람할 수 있습니다.


### 📱 Android, iPadOS/iOS
* **플로팅 내비게이터 크기 조정**: 검색이나 맞춤법 검사 등에 사용되는 플로팅 버튼의 터치 영역을 키워 터치스크린에서의 사용성을 높였습니다.


### 📱 iPadOS
* **스크롤바 버그 수정**: 사이드 패널이 열려 있을 때 스크롤바가 항상 표시되어야 하지만, 사라지는 현상이 있었습니다.


## 3.0.3

### 🎛️ 공통
* **홈 버튼 버그 수정**: 파일 트리에서 열려 있는 마크다운 문서의 홈 위치가 시작 페이지로 설정되는 문제를 수정했습니다.
* **Mermaid 에러 방어**: Mermaid 렌더링 에러 발생 시 앱의 쉘이 손상되지 않도록 방어 로직을 추가하고, 회귀 테스트를 통해 예상 가능한 렌더링 문제를 수정했습니다.

### 🖥️ Windows, macOS, Linux
* **실행 파일 상세 정보**: 빌드 시 현재 버전이 올바르게 삽입되지 않던 문제를 해결했습니다.

### 📱 Android
* **문서 연결**: 마크다운 문서 연결 기능이 추가되었습니다.
* **문서 폴더**: 최신 안드로이드 기준에 맞게 수정하고, 앱이 사용하는 문서 폴더를 지정했습니다. 이로 인해 파일 접근 권한 요청이 나타날 수 있습니다.

### 📱 iPadOS/iOS
* **iCloud 문서 열기 방식 변경**: Finder에서 iCloud 파일을 열 때 앱 샌드박스를 거치지 않고 직접 열도록 변경되었습니다.





## 3.0.2

### 🎛️ 공통

* **아웃라인 패널**: 목록에 표시되던 마크다운 문법을 제거하고, 상위 계층에서 접을 수 있도록 개선했습니다.
* **파일 트리 패널**: 컨텍스트 메뉴를 통해 파일 이름을 변경할 수 있습니다.

### 🖥️ Windows, macOS, Linux
* **편집 모드 툴바 탐색 기능 추가**: 좁은 폭에서 가려져 마우스로 가로 스크롤해야 했던 툴바에 스크롤 버튼을 추가했습니다.

### 📱 iOS/iPadOS 및 Android
* **파일 트리 패널 개선**: 태블릿과 모바일에서 파일 트리 목록의 컨텍스트 메뉴를 길게 누르거나 컨텍스트 메뉴 버튼을 사용하여 호출할 수 있습니다.
* **새 문서 생성**: 이제 올바른 위치에 파일을 생성하고 저장할 수 있습니다.
* **컨텍스트 메뉴**: 데스크톱에서 사용되는 사용자화 된 컨텍스트 메뉴가 각 OS의 기본 컨텍스트 메뉴와 충돌하여 사용자화 된 컨텍스트 메뉴를 제거합니다.



## 3.0.1

### 🖥️ 공통
* **details, summary 태그 랜더링**: 내용 요약/접기 랜더링 버그를 수정했습니다.

### 📱 iOS/iPadOS 및 Android
* **iOS, Android UI**: 모바일(스마트폰)과 타블렛(iPad/Android Tablet) 환경에서 모든 UI 요소의 폰트 사이즈가 Apple Human Interface Guidelines (iOS/iPadOS Typography) 표준 규격에 일치하도록 최적화합니다

### 주요 변경 사항 (Highlights)
- **통합 사이드바 도입**: 파일 트리, 개요(Outline), 검색 기능이 통합된 사이드바 추가 (CTRL+ALT+S / macOS: CMD+OPT+S)
- **마크다운 구문 강조(Syntax Highlight)**: Python, Bash 등 코드 블록 렌더링 시 구문 강조 추가
#### 추가된 사항 (New Features)
- **사이드바 전용 단축키**: 파일 트리(ALT+1), 개요(ALT+2), 검색(ALT+3) 단축키 추가
- **에디터 삽입 기능 강화**: 파일 트리에서 하이퍼링크 및 이미지를 편집 중인 문서로 직접 삽입하는 기능 추가
- **표 삽입 시각화**: /table 명령어 입력 후 키보드 방향키를 이용해 직관적으로 표를 삽입하는 기능 추가
- **고급 이모지 삽입**: 키보드 탐색이 가능하고 카테고리별로 분류된 이모지 삽입 모달 창 추가
- **AI 다국어 번역 및 맞춤법 검사**: 편집 중인 문서를 원하는 언어로 일괄 번역하거나 맞춤법을 검사·교정하는 기능 추가
- **뷰어 전용 번역**: 편집 없이 현재 문서를 임시로 번역하여 보거나 번역본을 저장할 수 있는 기능 추가
- **목록 및 서식 옵션**: 순서 있는 목록(Ordered List)의 번호 증가 방식(1. 1. 1. 또는 1. 2. 3.) 선택 기능과 사용자 지정 형광펜 색상 선택 기능 추가
- **수준별 툴바 제공**: 사용자의 마크다운 숙련도에 따라 3가지 에디터 툴바(Beginner, Rookie, Pro) 세트 선택 기능 추가
- **뷰어 표시 설정**: 마크다운 뷰어의 기본 글꼴 변경 기능 및 여백 3단계 조절 기능 추가
- **탭 및 파일 관리**: 닫은 탭 다시 열기(CTRL+SHIFT+T), 다른 이름으로 저장, 최근 연 파일 목록 북마크(핀 고정) 기능 추가
#### 개선 사항 (Improvements)
- **팝업 툴팁 및 UI 개선**: 하이퍼링크 호버 시 목적지 주소 표시 및 다국어 지원, 이모지 토스트 알림을 Google Material Symbols로 변경
- **사이드바 사용성 강화**: 키보드 탭(Tab) 및 방향키 탐색 지원, 개요(Outline) 서식을 제목 크기에 따라 굵기/크기가 구분되도록 개선
- **파일 트리 편의성 향상**: 필터 클릭 시 지원되는 파일만 표시, 열려있는 파일 삭제 시 해당 탭 자동 종료, 우클릭 메뉴에 읽기 모드 전용 '새 탭에서 열기' 추가
- **편집 및 탭 경험 개선**: 미저장 상태를 나타내는 경고 아이콘 표시, 다른 파일 열기 시 새 탭에서 열림, 탭 닫기 애니메이션 추가, 편집 탭 복귀 시 이전 스크롤 및 커서 위치 기억
- **AI 및 작업 처리 고도화**: 번역 시 마지막 선택 언어 기억, OpenAI 및 LM Studio 모드에서 LLM 실시간 스트리밍(Delta) 응답 표시
- **다중 작업 안정성 확보**: 다중 탭 편집 시 탭 간 작업 내역 완벽 격리, 탭을 전환해도 번역/맞춤법 검사 작업이 유지되며 범용 진행률 표시줄로 상태 지속 표시
- **작업 스케줄링**: LLM 작업 진행 중 새 요청이 들어오면 이전 작업 완료 후 순차적으로 처리되도록 개선
- **시작 페이지 설정**: 최근에 열린 항목의 표시 개수를 사용자가 직접 조절할 수 있도록 개선
- **기능 통합 및 시각적 안정화**: 유사 기능 그룹화 및 통합, 읽기/편집 모드 전환 시 발생하는 화면 깜빡임 문제 제거
- **디자인 일관성**: DKST 시리즈 문서와의 일관성을 유지하기 위해 문서 아이콘 디자인 세부 조정
#### 버그 수정 (Bug Fixes)
- **성능 최적화**: 설치된 글꼴이 많은 환경에서 앱을 실행할 때마다 폰트를 다시 불러와 준비 시간이 길어지던 시작 속도 저하 문제 수정
- **AI 프롬프트 오류**: 에디터에서 AI 프롬프트 창을 닫아도 화면에 계속 남아있던 가시성 문제 수정
