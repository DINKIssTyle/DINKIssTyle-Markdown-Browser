# 3.0 拓展至全平台
<div align="center"><img src="icon-512.png" width="128"/></div>

<div align="center" style="font-size: 1.2rem; font-weight: 700;"> 轻巧优雅的跨平台<br>Markdown 查看器和编辑器！<br><br>现已支持 Windows、macOS、Linux、iOS、iPadOS 和 Android。<br><br></div>


## 3.0.2

### 🎛️ 通用

* **大纲面板**: 移除了列表中显示的 Markdown 语法标记，并支持在更高层级进行折叠。

### 🖥️ Windows, macOS, Linux
* **新增编辑模式工具栏导航功能**: 在窄窗口宽度下工具栏被遮挡时，新增了滚动按钮，无需再用鼠标横向滚动。

### 📱 iOS/iPadOS 及 Android
* **文件树面板改进**: 在平板和手机端，可通过长按文件列表项或点击右键菜单按钮呼出上下文菜单。
* **新建文档**: 现可在正确的位置创建并保存文件。
* **上下文菜单**: 移除了在移动设备上与系统原生菜单冲突的桌面端自定义右键菜单。



## 3.0.1

### 🖥️ 通用
* **details, summary 标签渲染**: 修复了内容摘要/折叠渲染的错误。

### 📱 iOS/iPadOS 及 Android
* **iOS、Android UI**: 移动端（智能手机）与平板端（iPad / Android 平板）环境下，所有 UI 元素的字体大小均经过优化，以严格契合 Apple Human Interface Guidelines (iOS/iPadOS Typography) 标准规范。





## 往期更新日志

<details>
<summary><b>版本 2.2 期间变更事项</b></summary>
  
### 主要变更 (Highlights)
* **完美支持元数据 (Front Matter)**
  * **识别与显示：** 打开包含 Front Matter 的文档时，地址栏会出现感叹号按钮，文档标签页将显示元数据中定义的标题。
  * **插入模板：** 在编辑模式下点击感叹号按钮，可轻松插入包含标题（文档首行）、作者（关联设置值）、日期（创建时间）、标签、草稿状态等的基础模板。
* **编辑与预览模式进阶**
  * **分屏控制：** 自由切换横向/纵向分屏方向，并随心切换编辑器与预览区的布局位置。
  * **比例调节：** 拖动分割条即可调整比例，双击分割条重置为 1:1 比例。
  * **开启/关闭预览：** 可通过工具栏按钮或快捷键 (`Ctrl+G` / `CMD+G`) 轻松控制预览。
* **应用内更新支持**（桌面版）
  * 无需访问网站，即可在应用内（设置 → 更新）直接检查并下载新版本。（目前支持手动下载而非自动更新）
#### 改进 (Improvements)
* **偏好设置 UI 全面重构：** 设置界面焕然一新，采用更现代精致的设计风格。
* **界面自定义：**
  * **主工具栏：** 可以在设置中开启或关闭新建文档、编辑模式、翻译、字号、主题按钮的显示。
  * **滚动条：** 应用自定义强调色，可直观查看当前滚动位置，并可选择显示时机（始终显示或滚动时显示）。
* **历史导航反馈：** 显著提升了在 Windows、macOS、Linux 上通过触控板手势前进/后退时的视觉反馈与动画流畅度。
* **最近列表清理改进：** 点击“清除最近列表”时，除用户固定的文件外，清理其余列表项。
* **增强 CJK（中日韩）语言兼容性**
  * **换行与提交改进：** 开启 `CJK IME Enter Fix` 选项时（macOS、Linux），输入 CJK 字符期间只需按一次回车键即可顺畅换行。
* **输入冲突解决：** 修复了在编写列表或使用命令 (`/`) 时，因按回车或方向键导致字符错误提交或无法进入下一步操作的问题。
#### 错误修复 (Bug Fixes)
* **文本选择错误修复：** 解决了切换标签页或打开设置窗口后滚动页面时，光标从上次编辑位置到新位置出现意外文本选中的问题。
* **低分辨率支持：** 为防止在 1280x720 等低分辨率环境下标题栏消失，应用启动时会自动以最大化模式打开。
* **macOS 导航错误修复：** 修复了在 macOS 上使用触控板和鼠标无法前进/后退历史记录的问题。

<details>
<summary><b>版本 2.1 期间变更事项</b></summary>
  
### 主要变更 (Highlights)
- **引入集成侧边栏**: 添加了集成了文件树、大纲 (Outline) 和搜索功能的侧边栏 (CTRL+ALT+S / macOS: CMD+OPT+S)
- **Markdown 语法高亮 (Syntax Highlight)**: 渲染 Python、Bash 等代码块时添加了语法高亮
#### 新增功能 (New Features)
- **侧边栏专用快捷键**: 添加了文件树 (ALT+1)、大纲 (ALT+2)、搜索 (ALT+3) 快捷键
- **增强编辑器插入功能**: 添加了从文件树直接将超链接和图像插入到正在编辑的文档中的功能
- **表格插入可视化**: 输入 `/table` 命令后，可使用键盘方向键直观地插入表格
- **高级 Emoji 插入**: 添加了支持键盘导航并按分类归类的 Emoji 插入模态窗口
- **AI 多语言翻译和拼写检查**: 添加了将正在编辑的文档批量翻译为所需语言或检查并纠正拼写的功能
- **仅查看器翻译**: 添加了无需编辑即可临时翻译并查看当前文档或保存翻译版本的功能
- **列表和格式选项**: 添加了有序列表 (Ordered List) 编号递增方式 (1. 1. 1. 或 1. 2. 3.) 的选择功能以及自定义荧光笔颜色选择功能
- **按难度提供工具栏**: 添加了根据用户的 Markdown 熟练程度选择 3 种编辑器工具栏 (Beginner, Rookie, Pro) 集合的功能
- **查看器显示设置**: 添加了更改 Markdown 查看器默认字体功能以及 3 级边距调节功能
- **标签页和文件管理**: 添加了重新打开已关闭标签页 (CTRL+SHIFT+T)、另存为、以及在最近打开文件列表中添加书签（固定）的功能
#### 改进事项 (Improvements)
- **弹出提示框及 UI 改进**: 鼠标悬停在超链接上时显示目标地址并支持多语言，将 Emoji 吐司通知更改为 Google Material Symbols
- **增强侧边栏易用性**: 支持键盘 Tab 键和方向键导航，改进大纲 (Outline) 格式，使其根据标题级别区分加粗和字号
- **提升文件树便利性**: 点击过滤器时仅显示支持的文件，删除已打开的文件时自动关闭对应标签页，在右键菜单中添加只读模式专用的“在新标签页中打开”
- **改进编辑与标签页体验**: 显示表示未保存状态的警告图标，打开其他文件时在新标签页中打开，添加标签页关闭动画，返回编辑标签页时记住之前的滚动和光标位置
- **AI 及任务处理升级**: 翻译时记住上次选择的语言，在 OpenAI 和 LM Studio 模式下实时显示 LLM 流式 (Delta) 响应
- **保障多任务稳定性**: 多标签页编辑时完全隔离标签页间的操作历史，切换标签页时仍保持翻译/拼写检查操作，并通过通用进度条持续显示状态
- **任务调度**: 当 LLM 操作正在进行中收到新请求时，将在前一任务完成后按顺序依次处理
- **起始页设置**: 改进为允许用户手动自定义显示的最近打开项目数量
- **功能整合与视觉稳定**: 分组并整合类似功能，消除在阅读/编辑模式切换时发生的屏幕闪烁问题
- **设计一致性**: 微调文档图标设计，以保持与 DKST 系列文档的一致性
#### 错误修复 (Bug Fixes)
- **性能优化**: 修复了在安装了较多字体的环境下每次启动应用时都要重新加载字体导致准备时间变长、启动速度下降的问题
- **AI 提示词框错误**: 修复了在编辑器中关闭 AI 提示词窗口后仍留在屏幕上的显示问题
- **AI 拼写检查错误**: 改进 LLM 响应解析逻辑，修复了拼写检查 (SpellCheck) 偶尔失败的问题
- **渲染错误**: 修复了渲染 TASK 格式时会额外输出不必要 '•' 符号的问题
- **图表可读性**: 修复了渲染类图 (Class Diagram) 时背景与文本颜色对比度不足导致文字难以看清的问题
- **解决快捷键冲突**: 解决了因功能扩展引起的快捷键冲突问题，并对相关快捷键进行了统一调整（已反映在起始页底部的文档中）
</details>
