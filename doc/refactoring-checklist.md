# 코드 정리 작업 목록

요청 순서에 따라 진행하며, 기존 미저장 문서 보호 및 비동기 전환 회귀 테스트를 유지합니다.

- [x] 1. 미사용 코드 제거: 호출되지 않는 함수·상태·import·CSS와 Android 잔재 제거
- [x] 2. 탭 처리 중복 통합: 활성화 흐름과 경로 검색을 공통화하고 중복 스냅샷 제거
- [x] 3. 상태 동기화 분리: 화면 렌더링에서 백엔드 동기화를 제거하고 상태 변경 지점에 명시
- [x] 4. 모듈 분리: 에디터의 독립된 기능을 별도 모듈로 분리하고 외부 호출 경로 정리

검증: 단계별 프런트엔드 테스트·빌드, 관련 Go 테스트, 최종 참조 및 의존성 검사.

1단계 검증: 프런트엔드 85개 테스트, Vite 프로덕션 빌드, `go test ./internal/app` 통과.
2단계 검증: 탭 클릭·재정렬·닫기 보호 및 경로 검색 회귀 테스트 추가, 기존 테스트 및 프로덕션 빌드 통과.
3단계 검증: 동기화 전송·중복 제거·실패 재시도 테스트 추가, 프런트엔드 92개 테스트 및 프로덕션 빌드 통과.

4단계 완료:
- `editor-appearance.js`: 색상 프리셋, 색상 정규화, 테마 확장 및 CSS 적용
- `editor-search.js`: 검색·치환과 검색 UI 상태, 중복 검색 루프 통합
- `editor-pickers.js`: 표·옵션·이모지 선택 모달
- `editor-layout.js`: 분할 화면, 미리보기 표시 및 레이아웃 저장
- `editor-view.js`: 기능 모듈이 공유하는 CodeMirror 뷰 참조
- `spellcheck-text.mjs`: 텍스트 분할, 좌표 복구 및 맞춤법 제안 병합
- `bundled-documents.js`: 탐색과 편집 미리보기에서 사용하는 내장 문서 로더. 기존 편집 미리보기의 정의되지 않은 로더 참조도 해결.

상태 동기화는 `main-session.js`와 전송 로직인 `session-sync.mjs`로 분리했습니다. 탭 렌더링에서는 전송하지 않으며, 편집·저장·이름 변경·탭 전환 및 제거 시 명시적으로 동기화합니다.

최종 검증:
- 프런트엔드 테스트 100개 통과 (기존 85개 + 회귀 테스트 15개)
- Vite 프로덕션 빌드 통과. 기존 500 KiB 초과 번들 경고는 남아 있음
- `go test ./...` 통과
- iOS 보조 스크립트는 개별 `go test <파일>`로 각각 컴파일 확인. 개별 실행용 `main()` 충돌을 막도록 `//go:build ignore` 지정
- 소스 모듈 40개의 정적 import/export 연결 검사 통과
- 미사용 import·지역 변수 및 정의되지 않은 참조 검사 통과, `git diff --check` 통과
- `main-editor.js`: 5,640줄 → 3,991줄
- 네이티브 UI와 실제 모바일 기기에서의 수동 검증은 수행하지 않음
