# FEATURES

本ドキュメントでは、DKST Markdown Browserの機能について説明します。
DKST Markdown Browserを使用すると、Markdownドキュメントを読み取り、編集し、新規作成することができます。

## Common

- **Markdownを開く**: Markdownドキュメントを開くことができます。
- **サイドバー - ファイルツリー**: 開いているドキュメントのディレクトリ構造を閲覧できます。
- **サイドバー - 検索**: 開いているドキュメントおよびサブフォルダ内のキーワードを検索できます。
- **画像ビューア**: ファイルツリーを通じて開いた画像を閲覧したり、拡大・縮小などの基本機能を提供します。
- **キーボード操作**: ほとんどの機能にキーボードからアクセスしたり移動したりできます。
- **対応拡張子**: `.md`, `.markdown`

## Reader
#### DKST Markdown Browserは、ハイパーリンク化されたMarkdownドキュメントの閲覧に優れており、以下の機能を提供します。

- **サイドバー - アウトライン**: Markdownドキュメントの構造を視覚的に表示し、目次のように整理することで素早く該当箇所へ移動できます。
- **ハイパーリンクナビゲーション**: ハイパーリンク化されたMarkdownドキュメントをウェブブラウザのように閲覧できます。
- **ホーム機能**: 最初に見つけたドキュメントがホームとなり、ハイパーリンクで別のドキュメントに移動しても容易にホームに戻ることができます。
- **フォントサイズ調整**: ボタンまたはキーボードショートカットでドキュメントのフォントサイズを簡単に調整できます。
- **ライト/ダークテーマ**: 好みに応じて明るいテーマと暗いテーマを選択できます。
- **印刷機能**: ドキュメントを印刷できます。
- **レンダリングエンジン**: `Marked` または `Remark` から選択できます。
  - レンダリングされる項目
    - **数式**: `katex*` を使用してLaTeX数式をHTMLでレンダリングします。
    - **ダイアグラム**: `Mermaid` を使用してMermaidコードブロックをSVGでレンダリングします。
    - **シンタックスハイライト**: `highlight.js` を使用してコードブロックをレンダリングします。

## Editor

#### DKST Markdown Browserは`CodeMirror`を内蔵し、モダンなMarkdownドキュメント編集環境を提供します。

- **シンタックスハイライト**: エディットの可読性を向上させるシンタックスハイライト機能をサポートしており、設定からプリセットを選択したり、カスタムカラーパレットを構成したりできます。
- **`/` ショートカット**: エディット中に `/` キーを入力することで、マウス操作なしにツールバーの機能を利用できます。
- **リンク挿入**: `URL` または `ローカルドキュメント` を簡単に挿入できます。`ローカルドキュメント`を挿入すると相対パスで入力され、ドキュメント作成が容易になります。
- **画像挿入**: `URL` または `ローカル画像` を簡単に挿入できます。`ローカル画像`を挿入すると相対パスで入力され、ドキュメント作成が容易になります。
- **ファイルツリー経由の挿入**: ファイルツリーからドキュメント、ファイル、または画像を選択し、右クリックメニューを利用することで、該当アイテムをエディタカーソル位置に直接挿入できます。
- **インテリジェントなパス判断**: ドキュメントや画像を挿入する際、パスに空白が含まれる場合、汎用性のために`<`と`>`で囲みます。
- **編集中のハイパーリンク移動**: 編集中にハイパーリンクをクリックすると、そのドキュメントがビューアに表示され、元の編集中のドキュメントに戻るか、新しいタブで開くフローティングボタンが提供されます。
- **エディタとビューアのスクロール同期**: エディット画面とレンダリングされたビューアのスクロール位置を同期します。オプションで無効にできます。
- **検索と置換**: 編集中のドキュメントのテキストを検索したり、一括置換したりできます。
- **CJK互換モード**: `CodeMirror`と日中韓の入力方式である`Marked Text`入力との互換性のために提供されており、不要な空行の発生を防ぎます。
- **エディタフォントサイズ調整**: ボタンまたはキーボードショートカットで編集画面のフォントサイズを簡単に調整できます。

>[!TIP] [基本ショートカット](frontend/public/SHORTCUTS.md)について知ってください。ショートカットキーを使うと非常に便利です。

## Editor with AI Assist
DKST Markdown Browser はローカルLLMを活用したAIアシストを提供しています。この機能を設定したり、オン/オフにしたりするには、エディタ設定のAI項目をご確認ください。

- **AI機能ツールバー**: 機能が有効になると、エディタの左下に`AI`フローティングボタンが表示されます。
  - AIボタンをクリックすることで機能を一時停止できます。
  -展開ボタンをクリックすることでAI機能ツールバーをすべて表示または折りたたむことができます。
     - **Temperature**: 温度を調整することでAI応答の創造性を制御できます。温度が高いほど、AIはより創造的な応答を生成します。
     - **Autocomplete**: Fill-in-the-Middle (FIM)機能をオン/オフにします。適切に機能させるには、適切なLLMモデルを選択する必要があります。
     - **Context+**: アシストするために選択したテキストの前後の内容の一部を文脈として使用します。より多くのコンテキストバジェットと処理時間が必要になる場合があります。
     - **Github Compatible**: GitHub用のドキュメントを作成する場合は、AIがGitHub Flavored Markdown (GFM) 仕様に合わせたアシストを試みます。
     - **Talk to me**: AIがユーザーの応答を処理し、**毎回**処理内容を簡潔に報告します。

### AI機能の使い方ガイド

#### テキスト選択によるAIアシストを受ける
1. 編集中の文章を選択します。文章を選択するだけでAIプロンプトウィンドウが表示されます。
1. `/`キーを押すと、すぐにプロンプトを入力できます。
1. 以下のように気軽に試してみてください。「文章を改善」「英語に翻訳」など。
1. 選択した文章が改善されたり、翻訳されたりしているはずです。

プロンプト例：「表にまとめてください」「divで囲んで中央揃え、幅128px」「小文字に変更」「文章を分かりやすく書き直してください」「スペルチェック」「ダイアグラムで描いてください」

#### テキスト選択なしのAIアシストを受ける
1. `/`を入力し「Ask AI」を選択（Enterキー）すると、AIプロンプトウィンドウが表示されます。
1. ショートカットキーでもAIプロンプトを呼び出すことができます。「CTRL+/」または「⌘+/」。
1. 以下のように気軽に試してみてください。「果物と野菜をそれぞれ10個の表で入力」「リンゴの効果をMarkdown形式で短くまとめてください」など。
1. 表にまとめられた果物や野菜、またはLLMによるリンゴの効果をご覧になれるはずです。

プロンプト例：「コードブロックの中に猫を描いてください」「PythonのHello Worldのサンプルを作成してください」

>[!Note] DKST Markdown Browserで動作するLLMは会話の文脈を保存しません。これはツールとしての役割に忠実であるためであり、以前の会話内容も記憶しません。また、インターネットや現在時刻、場所など、いかなる外部情報も参照することはできません。

- **推奨LLMモデル**
   - **3B～4B**程度の規模で、推論能力が不要または抑制できるLLMモデルを使用してください。
   - **AIアシストの品質**は、使用するLLMモデルによって大きく異なります。

## 上級者向け

### 前提条件

- **Go**: バージョン 1.23 以上
- **Wails**: バージョン v3.0.0-beta.3（Wails 3 は現在プレリリースです）
- **Node.js**: バージョン 18 以上 (npm含む)
- **CGOツール**: ネイティブコンパイルに必要（例: GCC または Clang）

### ソースからのビルド

#### macOS
macOSのビルドスクリプトは、汎用バイナリ（選択した場合）を生成し、アプリケーションバンドル(`.app`)を処理します。
```bash
chmod +x build-macOS.sh
./build-macOS.sh [arm64 | amd64 | universal]
```

#### Windows
Windowsのビルドスクリプトは、アイコンを含む実行ファイル(`.exe`)を生成します。
```cmd
build-Windows.bat [amd64 | arm64 | 386]
```

#### Linux
Linuxのビルドスクリプトは、特定のアーキテクチャに合ったバイナリを生成します。
```bash
chmod +x build-Linux.sh
./build-Linux.sh [amd64 | arm64 | arm]
```
